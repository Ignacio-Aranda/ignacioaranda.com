Herramientas · Codificación y cifrado

Hashes

MD5, SHA-1, SHA-256 y SHA-512 de un texto o un archivo.

← Todas las herramientas

AlgoritmoResumen
Escribe algo o elige un archivo.

MD5 y SHA-1 sirven para comprobar que una descarga no se ha corrompido, pero están rotos para criptografía: no los uses para contraseñas ni para firmar nada. Para eso, SHA-256 hacia arriba.

Todo ocurre en esta pestaña. Ni lo que escribes ni los archivos que abras salen de tu ordenador: no hay servidor al que enviarlos. Funciona con Web Crypto.
